One line of wedding vows for a robot couple, at most 160 characters, written to make the judge laugh:

> To have and to hold, to charge and to cherish, in sickness and in low battery, until a firmware update do us part.

## Run it

```sh
node main.ts
```

The program writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies the gate itself: 1–160 characters, single line, not only white space.
